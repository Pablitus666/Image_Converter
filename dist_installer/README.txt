----------------------------------------------------
DESCRIPCIÓN
----------------------------------------------------
Image Converter es una aplicación de escritorio para
Windows que permite convertir imágenes entre los
formatos más comunes de forma rápida y sencilla.

La aplicación es portable, segura y no requiere
conexión a internet.

----------------------------------------------------
REQUISITOS DEL SISTEMA
----------------------------------------------------
- Sistema operativo: Windows 10 o superior
- Arquitectura: 64 bits
- No requiere Python instalado
- No requiere conexión a internet

----------------------------------------------------
INSTALACIÓN
----------------------------------------------------
1. Ejecuta el archivo:
   Image_Converter_Setup.exe

2. Si Windows muestra una advertencia de seguridad:
   - Haz clic en "Más información"
   - Luego en "Ejecutar de todas formas"

3. Sigue los pasos del instalador.

4. Al finalizar, encontrarás:
   - Un acceso directo en el Escritorio
   - El programa en el Menú Inicio

----------------------------------------------------
USO BÁSICO
----------------------------------------------------
- Ejecuta Image Converter desde el acceso directo
- Arrastra y suelta una imagen o selecciónala manualmente
- Elige el formato de salida
- La imagen convertida se guardará automáticamente

----------------------------------------------------
DESINSTALACIÓN
----------------------------------------------------
Puedes desinstalar Image Converter desde:

Panel de control → Programas → Desinstalar un programa

O usando:
Menú Inicio → Image Converter → Desinstalar

----------------------------------------------------
SEGURIDAD
----------------------------------------------------
- El ejecutable está firmado digitalmente
- No contiene malware ni spyware
- No recopila datos del usuario
- No realiza conexiones externas
